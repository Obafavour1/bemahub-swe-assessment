DEFECT 1 — PERMISSION
================================================================================
Route: GET /wp-json/bemalearn/v1/me/earnings
Defect: Route used 'check_authenticated' instead of 'check_instructor'.
        Learners were allowed to access instructor earnings rather than being
        rejected with 403 Forbidden.

Fix: In wordpress-plugin/includes/class-bl-earnings-controller.php, changed
     'permission_callback' => [$this, 'check_instructor']

DEFECT 2 — SCHEMA MISMATCH
================================================================================
Route: GET /wp-json/bemalearn/v1/courses/1
Defect: Controller in get_course() read $row->lessons_total, which does not exist
        in table wp_bl_courses (the migration defined lesson_count). Consequently,
        lessonCount silently defaulted to 0.

Fix: In wordpress-plugin/includes/class-bl-courses-controller.php, changed:
     $shaped['lessonCount'] = (int) ($row->lesson_count ?? 0);

DEFECT 3 — API CONTRACT
================================================================================
Route: GET /wp-json/bemalearn/v1/courses
Defect: get_courses() selected all courses from wp_bl_courses without checking
        is_published = 1. Unpublished courses (such as course 5, Advanced Laminated Dough)
        were leaked to the public catalog in direct violation of the contract.

Fix: In wordpress-plugin/includes/class-bl-courses-controller.php, added:
     WHERE c.is_published = 1 to the SQL query.

================================================================================
DEFECT 4 — VALIDATION
================================================================================
Route: POST /wp-json/bemalearn/v1/me/withdrawals
Defect: create_withdrawal() checked if amount exceeded available balance, but
        failed to enforce amount >= MINIMUM_WITHDRAWAL_MINOR (50000). A withdrawal
        below the minimum was incorrectly processed rather than rejected with 422.

Fix: In wordpress-plugin/includes/class-bl-earnings-controller.php, added check:
     if ($amount < self::MINIMUM_WITHDRAWAL_MINOR) {
         return new WP_Error(
             'below_minimum',
             'The requested amount is below the minimum withdrawal.',
             ['status' => 422]
         );
     }
