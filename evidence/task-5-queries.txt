5.2 THE CONSTRAINT — DUPLICATE EVIDENCE & MIGRATION FIX
--------------------------------------------------------------------------------

Proof — Two inserts with the same instructor_id and payout_reference (both cancelled_at NULL):

SQL:

    (instructor_id, amount_minor, status, payout_reference, cancelled_at)

SELECT id, instructor_id, payout_reference, cancelled_at 
FROM wp_bl_withdrawals 
WHERE payout_reference = 'wd_duplicate_test';

Terminal Output:

Query OK, 1 row affected (0.002 sec)

+----+---------------+-------------------+--------------+
| id | instructor_id | payout_reference  | cancelled_at |

|  3 |             1 | wd_duplicate_test | NULL         |

Explanation:
MySQL treats NULL values as distinct in a UNIQUE index (per ANSI SQL standards). 
Because cancelled_at was part of the composite UNIQUE KEY (instructor_id, payout_reference, cancelled_at), 
rows with cancelled_at = NULL were permitted to duplicate indefinitely.


Applying the Forward-Only Migration (002_fix_withdrawal_reference.sql):

SQL:
DELETE FROM wp_bl_withdrawals WHERE payout_reference = 'wd_duplicate_test';
ALTER TABLE wp_bl_withdrawals DROP INDEX uq_reference;
ALTER TABLE wp_bl_withdrawals ADD UNIQUE KEY uq_reference (instructor_id, payout_reference);

5.3 A JOIN — ENROLMENTS & REVENUE PER COURSE
--------------------------------------------------------------------------------

SQL Query:
SELECT
    c.title,
    COUNT(e.id) AS non_refunded_enrolments,
    COALESCE(SUM(e.amount_paid_minor), 0) AS non_refunded_revenue_minor
FROM wp_bl_courses c
LEFT JOIN wp_bl_enrolments e
    ON e.course_id = c.id
   AND e.refunded_at IS NULL
GROUP BY
    c.id,
    c.title
ORDER BY
    c.id;

Terminal Output:
+------------------------------+-------------------------+----------------------------+
| title                        | non_refunded_enrolments | non_refunded_revenue_minor |
+------------------------------+-------------------------+----------------------------+
| Introduction to Bread Baking |                       2 |                       9000 |
| Sourdough Starters           |                       0 |                          0 |
| Pastry Fundamentals          |                       0 |                          0 |

| Advanced Laminated Dough     |                       0 |                          0 |

5 rows in set (0.003 sec)

Join Type Used:
LEFT JOIN: Retains all courses from `wp_bl_courses` even when there are no matching enrolments.
An INNER JOIN would omit courses with 0 enrolments (Sourdough Starters, Pastry Fundamentals, Cake Decorating Basics, Advanced Laminated Dough), violating the requirement.
